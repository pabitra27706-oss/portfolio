Learning philosophy

Four principles drive everything on this site:

  • Systematic documentation. If I learned it but didn't write it down, did I really learn it? Every topic gets code + notes + metadata.
  • Learning in public. Publishing my progress — including the challenges — keeps me honest and helps others.
  • Building real tools. This site itself is the biggest example: I needed a knowledge system, so I built one.
  • Long-term thinking. Small, consistent commits beat rare heroic sessions. This archive is designed for years, not weeks.
